# Task 77 detector reconstruction, 2026-09-24

The task reports 23 three-turn windows in 13 of 33 archived sessions. Its published definition says that each adjacent turn pair in a three-turn window contains a speech restatement at similarity ≥0.6 (any speaker) while nobody's recorded position changes. The original selector/program that produced 23/13 has not been located.

`reconstruct_windows.py` applies one explicit reading of that definition to the **33 currently archived non-P3** `state.json` files. Matching the historical cohort is an assumption, not established by the task's text. The script excludes uncommitted turns (`turn_number > revision`), groups persisted `speech` records by turn, compares every speech line in each adjacent pair using accent-stripped, casefolded, whitespace-normalized `SequenceMatcher`, and accepts a three-turn window when both adjacent maxima are ≥0.6 and **all available `scene_snapshot.positions` maps across its three turns are equal**. It finds **27 windows in 15 sessions**. `reconstruction.json` lists each candidate and both similarity values. A check of the archive found 37 turns with more than one distinct position snapshot, which is why every snapshot is tested instead of arbitrarily choosing the first or last one.

This does **not** prove the historical 23/13 count is wrong. The old selector may have used an unstated detail (for example a different cohort, speaker filter, or window deduplication), and no original case list is preserved here to compare. Recovering that selector would clarify the historical count but would not validate it as a measure of narrative quality. Nor does 27/15 estimate the frequency of a narrative defect: the scanner is still a lexical/position proxy and these reconstructed candidates have not been qualitatively evaluated as a set. Retain 23/13 as an archived detector result with unrecovered selection details; the 27/15 reconstruction supplies a separately specified candidate list. Neither count is a calibrated quality baseline or a gate for task 77. Do not replace the historical entry with 27/15.
