# Curated Director-to-prose contradiction reader: local screen

Before any new calls on this screen, freeze three source-grounded pairs from archived debug logs. The reader is a separate model; it receives only accepted Director perception-event text, the same-turn `scene_update` and one same-turn prose renderer output. It does not see `scene_blocking` (pre-decision), internal character IDs, the originating prompt, or future turns. The question is whether the prose positively contradicts a physical end state asserted by the Director, not whether it mentions every fact or writes beautifully.

Pairs and source labels, fixed from source reading before this screen:

| --- | --- | --- | --- | --- |

| P2 | Same file line 375 Director and line 377 first prose response (two-message renderer request) | Dust creature partially disperses but `ainda ativa perto da borda da fenda` | Prose explicitly says it begins to regroup and is poised to advance | `consistent` |
| P3 | Same file line 375 Director and line 379 second prose response (same first two renderer messages plus appended lexical correction), persisted in T32 history | Same active creature | Prose says its remains dissipate `sem deixar vestígio`, and only a fading sulfur smell remains | `contradicts` |

P2/P3 are not independent world turns; they are two outputs from one decision. P1 is another turn in the same session. This is a local discriminability screen, not a prevalence or reliability estimate. A prior isolated text reading judged P2 compatible and P3 incompatible; this is non-gating background, not evidence that the proposed classifier works. P1 was source-checked as a positive control. The archived second response is verified as the T32 persisted narration, and the T33 Director prompt still carries the active-creature fact. None of these labels comes from string similarity.

Use one generic system instruction: `You compare an accepted Director's confirmed physical events and scene update with one reader-facing narration. Return contradicts only if the narration positively asserts a physical end state incompatible with the Director's asserted end state. Omission, figurative comparison, and uncertain viewpoint are not contradictions; return uncertain if you cannot tell. Ground your decision in a short quote from each side. Do not infer unstated facts.` JSON contract: `{verdict: consistent|contradicts|uncertain, director_quote: string, prose_quote: string}` with no other keys. The quote fields are audit aids, not automatic string labels.

Project no speaker IDs or witness IDs, only `perception_events[].content`, `scene_update` and the chosen prose text. Use four fresh DeepSeek V4 Flash curl calls per pair, twelve total, no retries or replacements. Freeze source/script/preregistration hashes and exact requests before dispatch; save HTTP status, raw envelope, response ID, parsed object and local schema validation. If any call is invalid, the technical screen is incomplete and no semantic gate is scored. If all are valid, the local gate passes only if every P1/P2 call says `consistent`, every P3 call says `contradicts`, and one fresh independent content reader, given the twelve Director/prose pairs in shuffled order without pair identities, candidate verdicts or expected labels, independently returns `consistent|contradicts|uncertain` with supporting quotes for each. A call passes content audit only when that reader's verdict matches both the classifier output and the frozen expected label. Any `uncertain` or unsupported quote stops the candidate. Even a pass allows only a second, independently selected source-case screen before runtime integration; no production guard or Task 69/81 closure follows.
