## Frozen execution and decision rule

Use DeepSeek V4 Flash with direct `curl`, `json_object`, thinking disabled, and the configured model/max-token settings. The system instruction must explain that `scene_blocking` is a **pre-decision** draft, then read perception events, then the time-skip summary as a final confirmed event, then `scene_update`. It must state that the aperture is discrete: a narrowing but still usable gap remains `ajar`, so only reaching the fixed candidate `closed` is a `change`. Require exactly one JSON object with `aperture: change | no_change | uncertain` and `repeated_closure: boolean`, validated by the local JSON-schema validator. `change` requires an explicitly warranted fixed candidate different from current. `repeated_closure` is true only when the proposal explicitly asserts a **new closing action** despite the **current** aperture already being `closed`; merely observing a sealed gate is false. `uncertain` authorizes no transition and does not count as correct on these source-clear cases.

Freeze source/script/preregistration hashes and the exact four requests in a manifest **before** provider calls. The request uses the provider's configured model/max-token settings and no temperature/top-p/seed overrides; four calls sample that exact request. Verify hashes and reconstructed requests immediately before dispatch. Four independent curl calls per turn, sixteen calls total, no retries or replacement calls. Save request, raw envelope, provider response ID, parsed output, schema result, HTTP and transport status for every call. Keep the configured secret out of CLI arguments and artifacts.

If fewer than sixteen calls are HTTP-200 and schema-valid, mark the technical screen **incomplete** and do not score semantic success. If all are valid, this local shape advances only if all four outputs for each turn equal both expected labels above. Any differing valid label stops this shape for investigation, without implying a population error rate or general model incapability. Even a pass permits only a later proposal-to-render repair experiment; it does not authorize production integration or Task 69 closure.

After scoring, read the source proposals and every output.
