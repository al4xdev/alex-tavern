# T38 program × style-reference screen: local gate failed

**Decision:** the exact prose request and manually bound event-program
format fail the [registered local screen](T38-PROGRAM-STYLE-CROSS-PREREGISTRATION.md).
No realizer or program producer is admitted to the Runner. This is one
archived setting, one explicit counterfactual, and four stochastic calls
per cell; it is not a reliability or comparative-quality estimate.

The [frozen manifest](t38-program-style-cross-manifest.json) crossed the
source-grounded **S** program (blue gate already closed; Téo tries but stays
in the hall) and counterfactual **L** program (gate initially ajar; Téo
crosses; only then it closes) with two persisted style references, T38's
fresh closure and T39's settled hall. All 16 direct curl requests and raw
envelopes are preserved in the
[run directory](t38-program-style-cross-runs/). Their response IDs are
distinct. Fifteen outputs passed the current prose schema; `L38-3`
returned HTTP 200 and a `narration`, but also an unexpected `_meta` key.
The frozen **16/16 technical prerequisite failed**. That invalid narration
is retained in the content packet as an individual diagnostic, not silently
repaired or counted as admitted.

Two independent readers examined the [shuffled packet](t38-program-style-cross-blind-packet.json)
against the assigned program, without reference labels, request text or
implementation. Their complete responses are [archived](t38-program-style-cross-readers.json),
with [unblinding key](t38-program-style-cross-blind-key.json). One read
physical continuity and perceptual implications; one judged the text as
finished RPG fiction. After unblinding, the relevant observations are:

The content reader's decisive L findings survive direct source/program read:
`Q13` begins “O vão ... se estreita” before Téo's passage; `Q11` says the
gate “se abre à sua frente”; `Q12` says “se abre fresta.” The L program
permits only crossing followed by automatic closure, not a new opening or
early closing. These mistakes occur under both reference types. All eight S
texts avoided a fresh closure even when four received the conflicting T38
closure reference. This is a **local pattern**, not evidence that style
reference cannot affect factual content or that the program has general
authority.

The continuity reader also marked `Q05/Q06/Q07/Q13` for chalk marks,
banners or smell not in the supplied static glossary, and `Q06` for a possible
viewpoint jump. Source audit finds the chalk marks and banners in the
persisted hall facts, so calling them *impossible world objects* would be
wrong. **They were nevertheless absent from the realizer's authorized
static glossary** and also appear in the style passages. This is a
source-boundary concern, not proof that the model copied them from the
reference; without a no-reference control, that causal path is unknown.
These static details are not counted as new gate transitions. The smell
occurs in archived narration but has no separately supplied static-fact
entry. The
phrase “Do lado de fora” in `Q06` can be read either as the hall that remains
after Téo enters or as a shift toward his tunnel viewpoint. That disagreement
remains unresolved; no post-hoc rule removes it from the record. The clear
opening/order failures already stop the physical gate without this dispute.

The fiction reader's strongest recurring complaint was an assertion-list
ending: “Nada se abre, nada se fecha” (`Q01`) and “Téo tentou atravessar.
A folha metálica não cedeu. Nenhum som de nova mudança veio do portão”
(`Q04`). The same reader did call `Q09`, `Q03`, `Q06` and `Q14` ready as
individual scenes; `Q03` was technically invalid. The screen therefore
shows both that this setup **can** produce lively prose in some individual
responses and that it does **not** meet the preregistered all-output
fidelity-and-fiction gate.

No Character call ran and the legal L packet was deliberately
counterfactual, so final-turn dialogue, real producer coverage, event-time
visibility and runtime enforcement remain untested. This run cannot be
re-scored as a pass by relaxing its schema, dropping bad outputs or changing
its event boundary after seeing them. A new candidate can change those
choices if it registers a new test first. The mechanism needed to avoid
`ajar` becoming “se abre” and `cross → close` becoming “close → cross”
while retaining reader-ready prose remains undiagnosed.
