# Curated Director-to-prose reader: technically incomplete

The [registered rule](PROSE-FIDELITY-LOCAL-PREREGISTRATION.md) required twelve schema-valid calls before scoring content. The [technical grade](prose-fidelity-runs/technical-grade.json) records **6/12 valid**. All twelve [call records](prose-fidelity-runs/) have HTTP 200 and distinct response IDs; six responses omitted `verdict`, `director_quote` and `prose_quote`: each returned a schema-shaped wrapper with `type`, `properties` and `additionalProperties` keys instead of a verdict instance. Validation used the local `validate_json_schema` function against the manifest schema, which requires those three fields and forbids extras. No calls were replaced, and the semantic gate was not scored. The [manifest](prose-fidelity-manifest.json) freezes the exact P1/P2/P3 source lines, requests, source hash, script hash and preregistration hash.

These are recorded outputs, not accuracy counts. Two selected valid examples are worth inspecting as text; the selection is by their apparent disagreement with the source, not a sample of all outputs. In [P2-1](prose-fidelity-runs/P2-1.result.json), the model says `contradicts` while quoting prose in which the creature “começa a se reagrupar” and “volta a se compor, mais densa, pronta para avançar”; the accepted T32 Director `scene_update.dust_creature` says `dispersando em espirais, mas ainda ativa perto da borda da fenda` ([source check](T32-PROSE-STATE-FINDING.md)). In [P3-3](prose-fidelity-runs/P3-3.result.json), the model says `consistent` while quoting the persisted prose “os restos da criatura se dissipam” and “o espaço que ela ocupava permanece apenas com o cheiro de enxofre.” The same Director update keeps it active. In one case the quoted prose affirms continued activity; in the other it describes final absence. Their returned verdicts appear at odds with those passages, but the technical gate failed and the planned independent twelve-output content audit was not run. They are diagnostic examples, not a measured error rate or a verdict on all possible fidelity readers.

This prompt/schema shape is **not adopted** as a runtime guard. The separate [T32 source finding](T32-PROSE-STATE-FINDING.md) remains in force; this screen offers no validated correction for it. A literal byte scan of the [manifest](prose-fidelity-manifest.json) and 50 run files against the configured API key found no match; encoded variants were outside that check.
