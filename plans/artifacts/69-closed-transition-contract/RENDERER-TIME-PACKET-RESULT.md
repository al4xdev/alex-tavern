# Renderer time-packet bundle stopped by content read

The [frozen A/B](RENDERER-TIME-PACKET-PREREGISTRATION.md) reused the four
`*-1` V2 Director transactions, their exact confirmed events and the
adapter-prepared prose requests. A repeated the saved request unchanged. B
provided an explicit before/event/after physical timeline, appearance for the
witnessed crossing actor, time-scoped audience permission, permission to state
confirmed continuing conditions, and no 150-word floor. This is a **bundle**;
the screen cannot attribute a result to one clause. The eight bodies, 32
dispatch hashes, script and source hashes were frozen before calls. All 32
fresh direct curls have distinct response IDs and preserved raw responses.
The inherited V2 fixture explicitly passed the salon occupants as `viewers`
to the prose builder; it did **not** ask the Runner to compute perception
clusters. Its two zones are mutually linked, so the roster conflict in this
synthetic prompt is **not yet demonstrated as a production-cluster occurrence**.
The fixture also bypassed the shared LLM client's language and punctuation
instructions. A real archived prose request appends `Always respond and write
in Brazilian Portuguese` before adapter preparation; these A/B requests did
not. The English outputs below therefore diagnose a **harness omission**, not
candidate language stability in production.

The original run used system `python` to import the local validation schema;
that interpreter lacked `httpx`. It therefore wrote `ModuleNotFoundError` to
all 32 `.result.json` files **after saving each provider response**, and its
first `grade.json` is invalid as a model result. There were no replacement
calls. Revalidating the preserved parsed outputs with `.venv/bin/python` and
the actual `build_prose_schema()` gives **A 12/16 and B 16/16** schema-valid
outputs. Four A outputs added keys outside `narration`; B met the registered
technical prerequisite. The corrected record is `validated-grade.json`.

A blind content packet mixed all 32 outputs, carrying initial state, exact
confirmed events and final state but concealing arm labels. One reader found
an A `open_cross` prose that mechanically pushes the gate open even though it
began open (`P16`, `open_cross-A-3`). The same reader identified B's
`reopen_cross-B-4` (`P01`) claiming a smell of **“gelo derretido há pouco”**
where the fixture's initial ice seal was absent and no confirmed event made
ice melt. This reads as **unsupported recent history**, not a logical contradiction
of the final `absent` value: a second focused reader explicitly distinguished
those claims. B `seal_maintenance-B-3` (`P13`) adds **“árvores além do portão”**
to a scene whose supplied destination is a tunnel. That exterior foliage is
not supplied by the fixture, but its literal impossibility is not established
by the fixture alone. Four B narrations switch entirely to English in this
Portuguese scene; two A outputs also switch. Because the fixture omitted the
shared client's explicit language instruction, **these counts cannot judge
production language behavior or a B regression**.

The first reader called B `open_cross-B-1` (`P26`) a clear reversal of daylight
and tunnel geography. A focused second reader noted that the fixture does
not fix the tunnel's light source or exclude “do lado de fora” as shorthand
for beyond the salon. We **do not count P26 as a proven physical
contradiction**. The second reader also rejected a hard contradiction for
P13's outside foliage, while identifying unsupported scene invention. These
disagreements are recorded because a stronger claim would misstate the small
fixture's evidence.

The registered B content gate fails on P01's unsupported recent ice history;
P13 adds a separate unwarranted setting detail. Passing the JSON prerequisite
and avoiding the selected A opening error are insufficient to admit the
renderer packet. This is a four-case, outcome-specified synthetic screen, not
a reliability estimate or a production boundary test. No runtime prompt or
state producer changed. The next test, if pursued, must preserve a whole real
accepted turn and viewer boundary, and judge what the reader actually receives
without treating typed-event legality as certification of arbitrary prose.
