# Bounded portal trace, before calls

Four independent synthetic traces use the experimental events-last request
variant. This variant passed the exact act flags in its fresh replication but
has not passed content review: one earlier candidate extinguished already-dark
runes. No production patch or Task 69 admission follows from this experiment.

Start with the frozen failed-attempt fixture, at its actual coverage trigger.
Make a real curl and apply its response through production replan_roteiro using
a local response transport. Require act_index=0: an attempt is not success.
Then commit a scripted Narrator confirmation that settling runes fully close
the portal (T3), a short character question (T4), and a short Bento observation
(T5). The same current roteiro accumulates actions, authoritative anchor
evidence and history. Evaluate production clocks/cooldown after each step.
Only call the planner when the controller requests it; apply each real result.
Stop the trace when the old act advances or after T5. This allows up to three
committed observations after closure; no same-turn advance is required.

Every dynamic request is captured through the actual builder/client/adapter,
then receives the exact experimental status/system-boundary/events-position
transformation. It is not the production prompt. Store requests, raw results,
provider IDs, timing, canonical facts and decision observations. Four traces
run independently; no retries or substitution after failures. This protocol,
script and production sources are hashed before any call. No personal session
and no .data writes. Config is read only for the authorized provider call.

Mechanical gate: all four traces must have valid replies, no premature
act_index advance on the failed attempt, and old act_index=1 by the T5 bound
after confirmed closure. No open-portal assertion is inferred from mere anchor
coverage. A transport/schema failure makes a trace incomplete; an incorrect
act index or absence of advancement at the bound fails the respective gate.
No semantic reliability rate follows. If the mechanical gate passes, an
isolated reader checks each resulting plan against that trace's actual facts,
including the extinguished runes, before any production admission.

This is a bounded planner/controller experiment with scripted canonical
events, not full Narrator/Character execution, prose or persistence acceptance.
