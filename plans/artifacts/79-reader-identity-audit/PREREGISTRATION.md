# Reader identity audit: preregistration draft

1. OBSERVED, deterministic provenance failure. The archived `plans/artifacts/79-positional-audit/blind_read/results.json` has 40 rows from 20 distinct session IDs. Every row has `character == cid`, such as C11. In `blind_read_judge.py`, `collect()` resolves `c.get("name") or cid`, while the saved current-schema character has its name at `characters[cid]["mind"]["name"]`. `judge()` inserts `case.character` into PERSONAGEM. Thus the archived endpoint is 35 undeterminable judgments out of 40 ID-addressed inputs, not the documented experiment with canonical character names. This audit will retain the original files and results.

2. Decision fixed independently of new LLM outcomes: retire 35/40 as a validated canonical-name baseline and correct its method description wherever it currently supports task 79 or 80. A name-resolution invariant failed for 40/40 inputs; no empirical effect size can restore that provenance. This establishes neither that the prose was clear nor that ID input caused the old undeterminability. The causal effect on judgments remains unmeasured.

3. Controlled real-payload reconstruction: pin exactly the original 40 `(session, turn, cid)` rows in their saved order. Resolve session directories by the original sorted, deduplicated state-path enumeration, recording each chosen path and SHA-256. Reconstruct the original narration from that state's narration records for the turn, joined by two newlines and truncated to the original 4000 characters. Use the archived script's exact PROMPT string, hashed. Arm A supplies the archived ID string; B supplies the exact current-schema mind.name. Save both exact prompts and assert their only difference is PERSONAGEM. This is reconstruction of the previous requests: the old tool did not persist request envelopes, so original requests cannot be independently byte-verified. No claim of measuring a player's single-view narration; the original collector joins narration records across audiences.

4. Run three repeats of both arms for every case (240 calls) using curl, the configured DeepSeek model and the historical judge settings: max_tokens=800, json_object, thinking disabled. Randomly interleave all jobs using seed 790905, with at most six concurrent calls. No arm name or previous verdict enters a judge input. Record exact request, raw provider envelope, parsed answer, duration, HTTP status, model, source session and turn, and an audit agent label. Authentication is supplied on stdin and never logged. On authentication/account errors cancel pending work and report the completed denominator; a failed or invalid call is retained, never replaced. No production source edits or session mutations.

5. Fixed outcome accounting: verify the verdict is one of the three historical labels. Preserve empty or nonverbatim evidence as an evidence-quality flag, not a retry trigger; report it separately and read every determinate answer against its exact narration. No post-hoc relabeling of automatic output. Primary endpoint is the mean NAO_DA_PARA_SABER indicator per case over three repeats, averaged equally across original cases within each session, then compared B minus A per session. Report all 20 session values, unweighted mean difference, median, standard deviation, range and pooled counts. Repeats/cases are not independent sessions. No p-value or product-quality claim. If any calls are missing or malformed, report outcomes with explicit denominators and mark the primary complete-cohort comparison incomplete; do not discard inconvenient cases.

6. Interpretation rule registered before calls: report the observed difference between arms, its sign and magnitude, and the number of sessions in each direction and ties. A nonzero stochastic contrast alone does not establish name sensitivity or causation. No minimum-effect or significance claim. A zero mean means no mean difference was observed here, not equivalence. In either case claim 2 stands. Canonical-name B is an exploratory remeasurement of this selected historical sample, not a task-79 post-change A/B or acceptance of a narrative-quality fix. The endpoint reports the judge's movement labels, not verified movement inferability, current-position clarity or literary merit. The configured model may differ from the historical model; only the contemporaneous A/B comparison holds provider conditions together. If the evidence read exposes material judge failures, retain and report automatic counts but do not promote corrected B into a validated acceptance baseline.
