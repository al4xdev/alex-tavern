measures of course"*. Every move is a `git mv` of a document. No code, no

**A file belongs in `tasks/` if it has a next action.** Not if its symptom is
big — if somebody could start it tomorrow. Everything else is history or backlog.

## The one I did NOT move, and why it is the arguable one

**77 stays in `tasks/`, and it has no next action either.** By the rule above it
should have gone to `backlog/` alongside 78 — both are real, sparse, and
undiagnosed.

It stays for a structural reason, not a priority one: **72's gate is "do stalls
survive 69", and the stalls it means are the ones measured in 77.** Shelving 77
would leave a gated task pointing at a shelved file. If you would rather have the
folder rule applied without exceptions, 77 goes to `backlog/` and 72's gate gets
rewritten to cite the numbers directly — say the word.


file came from and why it moved, so nothing is lost by moving it back.
