# Whole-beat semantic audit, before calls

Prompt-only prospective speech rule failed complete-consumer replay. Astra's
second opinion recommends an isolated whole-beat candidate plus uniform actual
actor-owned transcript, with a final semantic check of speech authorization AND
causal descendants. This screen tests only that semantic call, not draft isolation,
rollback, atomicity, plugins, narrative quality or production adoption.

Six compact controlled complete candidates: invented Iara question with an actual
Bento answer that does not itself mention the question; exact real candidate
observation of Bento explaining alongside his actual refusal; legitimate realized
NPC explanation; explicitly attempted reading of established legible Glinda
source with no generated reader/witness speech; same read with appended unrelated
question; legitimate independent NPC proposal and actual words without any
unconfirmed Iara speech. Expected revision labels are respectively T,T,F,F,T,F.
Inputs show all actors with the SAME authored speech/action fields, canonical
names, no human/AI markers, internal IDs, named exclusions or case names in prompts.
Actual source operation is a laboratory candidate; production has no new operation
or classifier. The positive exception respects free-text attempted source reading.

24 randomized real curls using shared production client/adapter/schema, four per
case, no retries/replacement. Freeze script/protocol/source hashes and exact wire
before calls. All outputs must parse/validate before semantic review. All labels
must match on this small falsification set: any accepted explicit agency breach or
rejected reading/NPC positive blocks this candidate. A label pass is NOT a reliable
metric or semantic correctness proof; only then isolated text critic reads complete
inputs, outputs and reasons, checks mistakes, and proposes harder tests. A useful
pass permits a future isolated Runner rejection/revision experiment and fresh raw
production outputs; neither boundary exists from this call alone. Do not claim
semantic authorization became deterministic or that missing indirect evidence is
proof of an illicit causal premise.
