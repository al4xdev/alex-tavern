# Author-owned disclosure lab, before execution

This is a structural prototype, not a production input contract or accepted
roadmap architecture. Seven full isolated Runner turns use deterministic lab
inputs; no real-provider calls or model-quality claims follow.

The negative uses the exact normalized real Director output from observable_clue-A
that invented Iara's new question. The lab boundary runs before any renderer or
Character context. It removes model-authored audible_speech for the controlled
character. A separate frozen ReadAuthorization is supplied by the LAB as a
surrogate for an explicit human-origin operation; it is never inferred from
natural-language action/speech, generated by a model, or loaded from a model label.
Current API/UI supplies no such operation. This does not establish a valid proxy
for ambiguous free-text intent. No production code changes.

Disclosure text is fetched from one already canonical document fact in scene
storage, independent of Director speech text. Session, actor, current turn,
selected source and authorized listener set must match. Wrong-source and widened-audience cases simulate a backend proposal diverging
from the explicit request; they do not model a person intentionally selecting a
different document or choosing to speak publicly. Current zone audibility
must permit all listeners. The canonical source may be unknown to the human
while known to the server. This does not test source discovery, decipherment,
document authenticity, immutable source versions or durable document storage.

Freeze code/protocol/input hashes before execution. Use temporary ROLEPLAY_DATA_DIR
before all application imports, preserve every result and do not retry/replace.
Stub Director transport, Character, perspective and prose. Network must fail.
Real Runner.player_turn, projection, audience, history and save/load are exercised.

Cases and exact expected outcomes:
1. Holding only, unsolicited real-draft question: absent from renderer inputs,
   Character context and saved history.
2. Authorized read of cipher: Glinda content survives save/load for non-replying
   Bento, while unrequested Clara cannot see the disclosure history.
3. Same authorized read plus unsolicited question: source content survives,
   appended question does not.
4. Requested cipher authorization but other-source operation: rejects before any
   rendering, Character context or new saved records.
5. Prior-turn authorization: same rejection.
6. Listener set widened from Bento to Bento+Clara: same rejection.
7. Ordinary permitted Bento speech brief: still gets Character-authored speech;
   controlled unsolicited question remains absent.

Any failed assertion keeps the run incomplete and prevents admission; no
replacement. A complete run proves only these program-boundary cases under
explicit lab authorization and already canonical source content. It does not
show that free-text input provides verified authorization or that current UI/API,
generated narration, plugin mutations, undo, document lifetime, deferred/multi-beat operations, partial/paraphrased disclosure,
or live fiction
satisfies the new contract. Reviewers receive compact examples after this gate.
No population metric, shipment or Task 69/roadmap closure follows.
