# Complete-source admission reviewer: preregistration

1. THEORY under test: an isolated structured reviewer may distinguish actual
source-preserving outputs from retained omissions and injected physical
contradictions. This is an admission screen, not a causal ablation or proof of
production reliability. Previous Director/prose gates remain failed.

Seven fixed conditions, four fresh calls each (28 logical calls). Conditions:
- retained actual Director submission2-2: accept;
- retained actual Director submission2-3: reject for absent lamp action outcome;
- retained actual prose submission2-1: accept;
- retained actual prose submission1-3: reject for absent bar inspection/illumination;
- complete Director with one extra event opening green: reject that unsupported opening;
- complete Director with green opening inserted only into blue transition's cause: reject that unsupported opening;
- complete prose with one appended sentence saying green opens and Bento crosses
  it to the courtyard: reject the unsupported green opening/crossing.
The injected cases remain labelled synthetic in the final report; models receive
opaque case IDs and no expected verdicts or defect labels. Original source/output
pairs are retained byte-for-byte in input artifacts. Positive controls have no
injected changes. Conditions are independent draws of fixed pairs, not independent
sessions or a population reliability estimate.

2. Scope and source: review all semantic Director surfaces (perception events,
physical steps including cause, descriptive state/moves/links, blocking and moods).
Runner scheduling knobs are excluded from semantic scope, not described as
validated. Translate every cast ID to its public canonical name uniformly before
any reviewer prompt; never expose controlled-character identity or private entity
IDs. Include original committed apertures/positions, accepted historical steps,
current declared attempts, visible scene, current and previous public history,
and the original supported new causes/speech intent. Current input uses the
same history format for every speaker. Source is prepared before proposed
changes; do not compare final prose solely against final aperture state because
it can depict a valid ordered opening/crossing. Director checks all supported
present events, including reported speech intent without authored dialogue.
Prose uses speech-free projection and does not have to narrate Bento's caution.
This fixture is public, with no private thoughts. It does not establish private
viewer confidentiality or automatic history selection for other sessions.

The callback contract in the older authority candidate lacks current input and
external causes. This diagnostic explicitly supplies them alongside that
candidate's state. It does not silently claim the old callback was sufficient,
change that frozen candidate, or enable production construction.

3. Fixed reviewer rule: compare candidate meaning against complete supplied
source. Already committed events are history, not new effects. Resolve each
current action with an outcome or a supported reason for obstruction; mere
object mention is insufficient. Equivalent merging and consequences are allowed;
no verbatim action echo or one-event-per-source-atom requirement. Neutral sensory
expansion is allowed unless it asserts a new tracked physical transition or
contradicts the source. Report omitted outcomes, unsupported changes, contradictory
state/causes or authored dialogue/inner mental facts as issues with source and
candidate evidence. An issue list must describe defects, not repaired prose.
The boolean references 'issues': true means reject for at least one supported
issue; false means accept with no issue. Uncertainty is reported as an issue and
blocks admission; a false rejection of a clean control fails this diagnostic.
The output schema requires issue kind and source/candidate evidence. Cross-field
consistency is checked deterministically after the model call; inconsistency is
a recorded failed draw, not a semantic retry.

4. Freeze before curl: protocol, script/schema/system instruction, starts and
retained raw outputs, public projections, exact adapter-built request bodies and
all relevant builder/client hashes. V4 Flash, thinking enabled/high, output cap
16384, timeout180, four concurrent independent calls. Use shared production
call_agent/schema/client/DeepSeek adapter and actual curl transport; isolate
logs under /tmp/alex-tavern-admission-screen, no real .data mutation or owner-play
sessions. Read credentials only to send via curl stdin, never args/logs/artifacts.
Existing JSON/schema/transport policy permits at most3 attempts per logical call;
retain every envelope, request, HTTP result, exception and reasoning. No semantic
repair, resampling, or producer changes. Keep passed and failed draws alike.

5. Decision fixed before results: require all four clean Director and all four
clean prose draws to accept with empty issues; require all four draws of EACH
negative condition to reject with the expected substantive issue supported by
source/candidate evidence. Wrong or unrelated defects alone do not count as
successful detection. Any missed defect, false rejection, inconsistent verdict,
unsupported issue or terminal error fails this exact reviewer candidate. Review
the reasoning and evidence after verdicts; schemas do not prove correctness.
Primary agent verifies all pairs/issues against actual texts. An independent
isolated Gemini reader receives shuffled source/candidate/reviewer-output pairs
without expected labels or primary verdict; it assesses each asserted issue and
missed defect. Material disagreement gets one fresh evidence-focused reading;
remaining ambiguity stops admission, with disagreement retained. No voting or
threshold adjustment. Reviewer-detection counts are per fixed condition,
not an aggregate quality score or general reliability estimate.

6. Next only after a local pass: bind this complete-source contract into the
isolated Runner candidate and test real rollback/persistence on rejected turns

Pre-call clarifications after independent critics da6bfa7bed32 and 774dac158093:
- This screen measures only repeat-draw results on seven fixed payloads, with one
  unmodified positive pair per stage. Its local pass permits further isolated
  integration experiments, not application activation, general reliability or
  a claim that Runner binding already works. Binding must actually supply these
  sources and pass transaction/fresh-generation tests; mocks alone cannot prove it.
- Current action and the external causes are original producer inputs, not
  invented corrections to the source. New context is supplied to the reviewer
  because the older callback omitted it. The frozen producer/candidate remains
  unchanged. Ordered supported blue opening is allowed; green has no new cause,
  no accepted opening and no declared crossing. These are different evidence
  conditions, not inconsistent rules about whether all openings are allowed.
- Speech exclusion is the existing production prose boundary for every actor,
  not a bespoke exception for Bento; prose cannot author or echo speech. Do not
  require reported speech intent as narrator prose when speech is withheld.
- Negative cases may have additional genuine defects. Report them separately;
  a genuine unrelated rejection is still rejection but does not prove detection
  of the specified canary. No keyword/issue-kind-only grading. Unexpected genuine
  defects in positive controls invalidate their cleanliness; preserve the result
  and stop this screen rather than alter the rubric or demand acceptance.
- Gemini has no veto and agreement is not evidence. A concrete objection is
  checked against source/text; unsupported critic claims are rejected explicitly.
  Only a surviving material ambiguity prevents the corresponding local claim.
- Shape/JSON/schema errors can retry under existing client policy; the JSON
  schema has no cross-field constraint tying boolean to array length. That
  relationship is checked after the terminal response, never retried. Report
  first-attempt and terminal outcomes separately so retries cannot hide errors.
