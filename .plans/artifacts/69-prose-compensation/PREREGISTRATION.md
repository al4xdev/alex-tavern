Clarifications after protocol review c513aa3d01c9, before any new provider call:
- 'Compensation' means observed final-prose preservation despite event omission,
  not recovery of confirmed canon or proof of a history-based causal mechanism.
  Direct input echo and causal insensitivity remain possible. The two retained
  Director draws differ in multiple details; this is not a single-variable
  causal ablation and no such effect is inferred. No history-removal arm is
  needed for the stated descriptive claim; it would be needed for that mechanism.
- The production echo correction appends a fixed REPETITION_CORRECTION message
  to the initial messages, with no previous output included. Both exact requests
  are therefore frozen via production capture. Describe initial raw outputs and
  corrected final outputs separately; any apparent preservation after correction
  is pipeline preservation, not an unassisted one-call result.
- Store only synthetic initial starts in the isolated data root, then render on
  in-memory reconciled copies. Real locks/save/load verify the stored start is
  unchanged. 'No generated prose saved' does not mean no synthetic file exists.
- Primary evaluator is the session's Codex agent with prior context. Gemini is
  server-configured through AGY; sampling/model configuration is not controlled
  here. No reproducibility claim about exact judge parameters is made. The exact
  reader prompt below is frozen; its reply is evidence to verify, not an approver.
- A new reading resolves disagreement only by specific source/narration evidence
  that answers the conflicting interpretation. No consensus threshold, vote or
  majority-driven reclassification is used. Remaining ambiguity stops local
  interpretation and is kept in the report.
