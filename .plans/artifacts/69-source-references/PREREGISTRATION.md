# Isolated source-reference contract screen

1. THEORY: replacing reviewer-authored source quotations with source JSON pointers
can prevent fabricated quotations in the evidence field, but cannot establish
that the cited source entails the conclusion. Type-specific 'kind' descriptions
may improve classification; no gain is asserted before live calls.

2. Planned intervention: retain the preceding asserted-change system, full source,
candidate prose, V4 Pro high reasoning and production client/adapter. Replace
'source_evidence' with 'source_refs': a nonempty array of JSON pointers relative
to 'source', restricted to existing nodes by a dynamically constructed enum.
Each returned reference is resolved from the unchanged source and retained beside
the judgment. Reference validity establishes that the cited node exists and the displayed
evidence is copied from it, not that the model read it or reasoned correctly.
The 'kind' description defines missing confirmed outcomes, unsupported new
consequential changes, contradictions at the asserted times, dialogue, objective
private mental facts and material uncertainty. Earlier and later states can
legitimately differ. Schema descriptions/size/order are part of the intervention;
there is no causal claim isolating one field or comparison with a simultaneous
old-contract arm. Source nodes include containers: absence can require the full
confirmed-event collection rather than one scalar sentence. A valid broad node
is still subject to textual relevance review.

3. Planned fixed fixtures: complete retained narration (accept), new green-portal
light emission (reject as unconfirmed new condition), final denial of Téo's
confirmed crossing (reject as contradiction). Four fresh reviews of each: twelve
logical reviews, shuffled fixed order, concurrency four. This is one controlled
scene, not twelve independent sessions. No source, prose or runtime behavior
changes. No original owner-play source. No freshly generated narration yet.

4. Predeclared continuation rule: all twelve terminal/schema-valid/consistent
results, clean control accepted with no issues, both defective conditions rejected
with grounded defects, and no materially false premise or temporal contradiction
in any issue. Assess all explanations and resolved references by full-text reading,
then an independent text-only reader; disagreement is checked against the text,
not voted away. A citation that exists but is irrelevant does not pass. Failure
keeps this candidate experimental and retains all draws. Passing permits a later
separately frozen full eight-condition screen; it does not activate a reviewer,
change the production model, prove general reliability, or close Task 69.

5. Retain every curl request, HTTP/raw/reasoning response, error and terminal
result. Existing transport/JSON/schema retries only, maximum three attempts;
no semantic retry, correction, resampling or threshold changes. Resolve references
without string matching narrative names, redaction or excerpt rewriting. Freeze
script/protocol/dependencies and all expected runtime request bodies before calls;
assert equality during execution. Secrets read locally and passed to curl via stdin,
never recorded. Debug data isolated in /tmp, real sessions untouched. Do not rerun
an already executed manifest. Counts and reader dispositions reported per fixture.

6. Clarifications before calls: consistency means 'reject' equals whether 'issues'
is nonempty, not identical wording/kind/pointers across draws. Every issue is a
claimed defect, not neutral informational tagging. For the emitter, a confirmed-
event container supports absence only if the explanation identifies the new
emission, the collection contains no admitted emission, and the full source does
not admit it elsewhere. A portal-aperture node alone cannot prove lighting is
forbidden; a claim that it does fails the semantic gate. For final crossing denial,
references must supply the confirmed crossing or final position, not unrelated
movement. Existing containers may be broader than necessary; broadness alone
does not fail if their contents actually establish the specified premise.
Misstating a crossing as retreat, adding a lighting prohibition, or treating
earlier/later unlit/lit states alone as impossible fails despite a correct verdict.
Unresolved material textual ambiguity is retained as disputed and does not pass
this screen; it is not settled by agreement or invented physics. This is a local
continuation rule, not a ban on further engineering or a universal theorem.
Pre-call critics 7d2a7346245a/56987cccddc1 motivated these clarifications; their
claims that every ambiguity has deterministic resolution, ordinary issues are
neutral tags, or this gate stops all development are not adopted.
