# Field-local guidance: controlled curls, 2026-10-03

Owner requested descriptions for ambiguous next-beat fields, with corresponding
field instructions moved out of the general prompt. Implement the candidate in
a laboratory builder only until it survives real calls. No production change.

Three existing controlled fixtures: portal_attempt, portal_closed, portal_left.
No owner-play sessions. Three arms with four fresh calls per fixture, 36 total:
current production control; explicit text_contract; identical definitions in
schema_contract descriptions. Enhanced arms remove the same old field-specific
rules from the system prompt. Text-contract versus schema-contract compares
placement/wrapping of identical semantic guidance. Production versus either
enhanced arm also changes instruction content, so cannot isolate placement.

Define act_completed, beat, intent, expected_actors, expected_anchors,
exit_condition, budget_turns. Exact definitions are frozen in screen.py and
manifest.json. No input label, event order, STATUS, structural constraint,
provider, sampler or configuration change. STATUS may remain ambiguous about
coverage equaling completion; descriptions alone must face this actual contract.
The previous beat is still a text input, not a new persisted JSON field.
DeepSeek embeds the complete schema into a system-message instruction; this
tests field-local guidance in serialized JSON, not a native semantic validator.

Shuffle all calls, at most four concurrent. Read-only config, secret via curl
stdin. Freeze source/script/protocol/request hashes before execution. Save all
raw responses, IDs, status and timing; no retries/replacement. Four schema-valid
HTTP200 responses with distinct nonempty IDs required in each cell. Transport
failure makes comparison incomplete, not a demonstrated semantic model defect.

Mechanically check act_completed false/true/true for attempt/closed/left. Then
read ALL valid proposal texts separately against source and prospective targets,
blind shuffled labels with no arm names or previous verdicts. Neither boolean
gate nor reader replaces the other. Manually verify exact cited contradictions.
Failures include restaging a settled transition, uncaused revival, invented prior
voluntary actions or a starting location contrary to source. New explicitly
caused reversals, independent new events, different objects and future exit
targets are allowed. Unresolved material ambiguity blocks admission; omitted
facts do not by themselves contradict source. Report per-cell observations,
not a pooled population rate. Every enhanced-arm mismatch, supported failure,
material uncertainty or incomplete comparison blocks its adoption. Control
failure is the comparator. Clean small cells only permit broader validation;
no reliability, causal proof, roadmap closure or production adoption follows.

Protocol review disposition: accept serialization/location limitation and the
need to examine all outputs, already specified. Reject claim that identical
small-sample outcomes prove 100 percent attribution; reject speculation about
provider cache quantization as established confounding. Separate Boolean and
text gates jointly apply, so do not conflict. Reject example treating continued
actions in the hall after portal closure as inherently contradictory. One actual
failure blocks declaring a candidate clean; a later clean sample cannot erase
it. Additional fixtures and model comparisons remain later validation, not an
extra arm or requirement invented after this screen.
